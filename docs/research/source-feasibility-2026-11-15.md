# Additional novel-source feasibility: completed second-pass investigation

**Last verified:** 15 November 2026. **Historical research status:** no new domain was enabled when this assessment was written. **Subsequent development:** WuxiaClick now has a [rights-confirmed, capped 20-chapter range workflow](../../.github/workflows/wuxiaclick-download.yml) and [mixed-link bulk routing](../../.github/workflows/library-bulk-download.yml). ReadNovelFull has since recorded one complete live download, *Archean Eon Art* (766 chapters; [run #44791453169](https://github.com/RichardDaffern/Novel-Retriever/actions/runs/44791453169)); this is not proof that every listing works. The 21 November three-source audit and five-title index preflight are preserved in the [campaign report](../../campaigns/overnight/source-audit-report-20261121.md). Unrestricted WuxiaClick full-book export remains disabled; consult [current website support](../website-support.md#wuxiaclick-bounded-source-not-unrestricted-full-book-export).

**Follow-up live tests completed:** [HTTP-200 scenarios](source-test-evidence-archive.md) cover actual publicly readable first and final chapters for two WuxiaClick novels, the site's linked catalogue pagination, two LibRead-to-FreeWebNovel redirects, and NovelBin.cc chapter HTTP 429. Source permissions and full-book TOC completeness remain gating.

This is a **historical candidate-source assessment as of 15 November 2026**, not a live source inventory. The current capability matrix is [Website Support](../website-support.md). Since this assessment, the enabled source set includes NovelFull, FreeWebNovel, ReadNovelFull, bounded WuxiaClick and one narrowly allowlisted Scribble Hub same-author cross-post. WebNovel remains limited to public metadata/feasibility and authorised local saved-page imports, not general live chapter downloading. The single user-facing bulk workflow remains **Library - Bulk Download**, which automatically routes supported mixed novel URLs.

## Scope and evidence

- Reviewed WuxiaClick, AO3, Light Novel Pub/NovelCodex, Royal Road, LibRead, NovelBin and its lookalikes, BoxNovel, NovelGo, NovelArrow/NovelPing, NovelHi, NovelBuddy, Novel Fire, WTR-Lab, official Wuxiaworld and WebNovel.
- Inspected accessible book metadata, public chapter indexes, up to one publicly viewable sample chapter through web research, published source rules, current service status and available first-party export options.
- Ran **two metadata-only GitHub Actions experiments from Ubuntu runners**: [robots + HEAD #43724193316 (archived)](source-test-evidence-archive.md) and [robots + HEAD + one book/homepage GET #43724354923 (archived)](source-test-evidence-archive.md).
- For each candidate, the runner checked its robots file first. When robots explicitly disallowed the planned probe or robots could not be verified, the runner **stopped**. One site-homepage/book GET was allowed only when robots permitted it. No login, CAPTCHA, locked chapters or challenges were bypassed.
- For the second experiment, redirects were **not followed**. At most the first 12 KB of a public **book or homepage**, not a chapter, were inspected transiently to extract a title. No body text or EPUB was saved, uploaded or printed. Site availability is time-dependent. This is **not a licensed archiving or full-book download test**.
- Browser/web retrieval and a GitHub-hosted request are distinct tests. A 200 HEAD or GET does not imply public chapter downloads work or are permitted.

## Delivery decisions

**Ready to implement immediately:** **None.** Metadata reachability alone is insufficient to deliver trustworthy complete EPUBs, and several candidates have explicit restrictions or a current outage.

**Next source-specific gates, in order:**

1. **WuxiaClick:** obtain permission for this personal-use archiving scenario; then build a no-text catalogue consistency check. Treat 2,276 entries versus the reader's 2,277 denominator as a potential missing/shifted chapter. Compare the first, last, and exceptional ordinal entries, reject gaps, and preserve *indexed reading position*, not display chapter number. Only after successful gate perform two permissioned live chapter verifications, test offline parser fixtures, then add one isolated adapter to the *existing* auto-routing bulk workflow.
2. **AO3:** verify the official status page says EPUB downloads are restored. Apply AO3's personal-use and bot policies, conservative per-work pacing, and **private storage only**. The current public GitHub Actions artefact mechanism is inappropriate for content whose rights do not permit public hosting. Never bypass login or rate-limit measures.
3. **Royal Road:** continue using already-authorised local EPUB imports. The runner's direct 403 means a new hosted adapter is **not currently a practical next implementation**. Do not retry through a browser proxy or another IP to evade it.
4. **LibRead:** investigate whether any **independently hosted** novel provides unique authorised source content. If all useful items link to FreeWebNovel, add a *safe, explicitly verified URL hand-off* in future only if compatible, rather than downloading the same work twice.
5. **Other unverified domains:** hold until accessible policy + canonical book identity + complete TOC can be established. If robots disallow a candidate, stop. Never assume mirror domains share operators, rights or URL paths.

**Regression requirements for any future adapter:** strict HTTPS allowlist, same-site redirect rules, title and chapter-count verification, position continuity, challenge/locked-page detection, bounded rate/concurrency, staged verified EPUB/TXT/ZIP output, CRC/SHA-256 checks, resumable checkpoints, partial-success artefacts and failed-only retries, Linux/Windows tests using *synthetic* prose. No new website dropdown or competing bulk workflow.

**Conclusion:** This investigation is complete to the limit of available legitimate access. The remaining blockers are specific, not unspecified research: **rights** for WuxiaClick, **service recovery/privacy** for AO3, **403** for Royal Road, **site redundancy** for LibRead, **retirement** of Light Novel Pub, **unreachable or restricted access** for NovelBin/BoxNovel/NovelGo/NovelPing, and explicit terms for prohibited sources.
